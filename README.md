# Sorting-Simulator

A Java-based desktop application for visualizing and comparing popular sorting algorithms in real-time.

## Features

- Interactive visualization of sorting algorithms:
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Quick Sort
  - Heap Sort
- Custom array input, random array generation, or import from file
- Adjustable sorting speed (FPS slider)
- Step-by-step animation for learning
- Compare the efficiency (e.g., swaps or comparisons) of each algorithm
- Export arrays and results
- Simple, user-friendly graphical interface (Java Swing)

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher

### Running the Application

1. **Clone the repository:**
   ```sh
   git clone https://github.com/phinphyn/Sorting-Simulator.git
   cd Sorting-Simulator
   ```
2. **Compile and run:**
   ```sh
   javac -d bin src/SortAlgorithms/*.java
   java -cp bin SortAlgorithms.MainFrame
   ```

## Usage

- Use the buttons to select sorting algorithms or create arrays.
- Adjust the FPS slider to set the speed of the animation.
- Input your own array, generate a random one, or load from a file.
- Press "Compare" to see statistics for all algorithms.
- Export results using the export button.
